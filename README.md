# programming-practice-2026

My personal practice repository for 2026.  solutions to programming problems, mostly from LeetCode, along with notes on how each one works.

## Repository structure

Problems are grouped into a folder per month, and each problem gets its own folder inside that:

```
programming-practice-2026/
├── LICENSE
├── README.md
└── august/
    └── 2904-Shortest-and-Lexicographically-Smallest-Beautiful-String/
        ├── PROBLEM.md
        ├── SOLUTION.md
        └── response/
            └── reflection.md
```

Problem folders are named `<number>-<Problem-Title>`, so they sort by problem number within each month.

## What's in a problem folder

| File | What it holds |
| --- | --- |
| `PROBLEM.md` | The problem statement, worked examples, and constraints. |
| `SOLUTION.md` | The approach(es) — intuition, implementation, and complexity analysis. |
| `response/reflection.md` | My own write-up: how I actually attacked it, where I got stuck, and the pattern worth remembering. |
| Source file(s) | The working solution, e.g. `Solution.java`, alongside the notes. |

## Languages

Everything is currently written in **Java**. I'm planning to add **C** and **C++** as I learn them, so some problems will eventually have solutions in more than one language.

## Why

It's to get better at recognizing patterns, writing clean code under constraints, and being able to explain *why* a solution works, which is why each problem gets written-up notes and not just a code dump.
